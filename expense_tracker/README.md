# Expense Tracker CLI
A simple and clean Command Line Expense Tracker built with Python.
This application allows users to manage daily expenses directly from the terminal, store them locally, and view useful summaries.

# 📌Features
- Add a new expense with description and amount
- Update an existing expense
- Delete an expense by ID
- List all expenses in a table format
- View total expense summary
- View monthly expense summary (current year)
- Local data persistence using a JSON file
- Input validation and error handling
