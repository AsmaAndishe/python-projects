# 🧭 GitHub User Activity CLI
A simple and lightweight Command Line Interface (CLI) tool that fetches and displays the recent public activity of any GitHub user using the GitHub Events API.
This project helps you practice:
- Working with APIs
- Handling JSON data
- Building CLI tools
- Error handling
- Parsing command-line arguments
No external libraries are used — only the Python standard library.

# 🚀 Features
- Fetch recent activity of any GitHub user
- Display actions such as:
  -⭐ Starred a repository
  -🐛 Opened an issue
  -🔀 Created a pull request
  -📌 Pushed commits
  -📝 Created or deleted branches
- Clean and readable terminal output
- Works fully from the command line
- Graceful error handling for:
  - Invalid usernames
  - API rate limits
  - Network issues
